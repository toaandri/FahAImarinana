- Java ME (J2ME).
- MIDP 2.0.
- CLDC 1.1.
- LCDUI.

Aucune API.

## 4. RESPONSIVE DESIGN

Adapter automatiquement l'interface aux résolutions :
- 128 × 160 pixels.
- 176 × 220 pixels.
- 240 × 320 pixels.
- 320 × 480 pixels.

Prévoir :
- Des boutons adaptés aux écrans tactiles.
- Une interface compatible avec les petits écrans.
- Une navigation au clavier pour les appareils non tactiles.
- Des textes qui ne débordent jamais.
- Des contenus défilants.

## 5. ANIMATIONS ET INTERACTIONS

Créer uniquement des animations légères :
- Changement d'écran fluide.
- Effet visuel au clic sur les boutons.
- Changement de couleur des boutons sélectionnés.
- Défilement des publications.
- Apparition visuelle des messages.

Les boutons doivent être interactifs et permettre de naviguer entre les écrans.
