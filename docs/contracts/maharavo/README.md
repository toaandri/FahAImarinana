# Contrats proposés côté backend

Ces JSON Schema sont générés depuis `Backend/app/integrations/maharavo/contracts.py`.
Ils ne constituent ni une documentation officielle ni une preuve de compatibilité
avec une API Maharavo distante. Les vérifications croisées et de provenance sont
également réalisées par le validateur Python.

Voir [le rapport d’inspection](../../../Backend/MAHARAVO_INTEGRATION.md).
